
# SDGE Playwright Automation

## Overview
This project automates SDGE application scenarios
using Playwright and a Page Object Model framework.

## Automation Tools
- Playwright
- JavaScript
- Node.js
- Git and GitHub

## Continuous Integration
GitHub Actions automatically runs the Playwright
test suite when code is pushed to main or a pull
request targets main.

## Run Tests Locally
npm ci
npx playwright install
npx playwright test
